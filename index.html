Buzzer

React, Node.js, Express, Socket.IO, MongoDB, Tailwind

Code on GitHub
  • A Kahoot-style quiz for teams. A host opens a room and players join with a game PIN and team code, no signup.
  • Every question, reveal and result stays in sync across players over Socket.IO, with speed-based scoring and a live leaderboard.
  • Hosts sign in with JWT; passwords are hashed with bcrypt. The host can build quizzes with a countdown timer.

Nestlot

Node.js, Express, JWT, HTML, CSS, JavaScript

Code on GitHub
  • A property portal to buy or rent. Filter by city, type, price, bedrooms or keyword, save favorites and message owners.
  • Buyers, owners and admins each get their own permissions, with JWT stored in httpOnly cookies.
  • Owners manage their own listings; admins approve, reject or delete listings and manage users.

Marquee Events

Node.js, Express, SQLite, JWT, HTML, CSS, JavaScript

Code on GitHub
  • Two portals: admins create multi-session events, attendees search, filter and book tickets.
  • Attendees can reschedule to another date of the same event or cancel, backed by a SQLite database.
  • Admin-only routes are guarded, and logins use JWT with bcrypt-hashed passwords.
